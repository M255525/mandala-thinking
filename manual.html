操作手冊

「曼陀羅思考法產生器」把日本今泉浩晃提出的曼陀羅九宮格（Mandala Chart）思考法做成互動網頁：輸入一個主題，展開成中央 3×3 的「主題與 8 大延伸面向」，每個面向再各自展開成一張 3×3 的「8 個子想法」，共 9 張九宮格。所有格子都可以直接點擊手動編輯，AI 只是加速展開的選用功能。

什麼是曼陀羅思考法

把一張 9×9 的大表格拆成 9 個 3×3 小九宮格來理解：

  • 表格 A（中央九宮格）：中心格填主題，周圍 8 格填「圍繞這個主題最關鍵、彼此不重疊」的 8 個延伸面向。
  • 表格 B（8 張子九宮格）：每個面向各自變成一張新九宮格的中心，周圍 8 格填這個面向下具體可執行的子想法，總共 64 個子想法。
曼陀羅思考法的價值在於「強迫把模糊的主題拆到夠具體」——8 這個數字不是重點，重點是持續往下拆解，直到每一格都是可以直接行動的具體想法，而不是空泛口號。

操作步驟

  1. 在最上方「主題」欄位輸入想展開的主題，或直接點選下方 5 組內建範例快速開始（其中「食療送餐」附完整手打示範內容）
  2. 手動點擊表格 A 的 8 個面向格子直接輸入，或展開「API 連線設定」填入你自己的 LLM API 金鑰後按「🧠 AI 一鍵展開全部」，一次生成 8 大面向、64 個子想法、總結與行動建議
  3. 點表格 A 的任一面向格子，或用表格 B 上方的跳轉導覽列，可快速跳到對應的子九宮格
  4. 對某一個面向的子想法不滿意，可以只按該張子九宮格旁的「🧠 AI 重新生成此面向」單獨重來，不會動到其他面向
  5. 最下方填「整體思考方向總結」與「3 個立即可行動建議」（AI 生成時會一併產出，也可自行填寫）
  6. 完成後可「複製為文字」、「下載 .txt」，或按「🖨 列印 / 存 PDF」輸出成報告
所有內容自動存在這台瀏覽器的 localStorage，重新整理頁面不會遺失；不同電腦或清除瀏覽器資料就會不見，請自行下載 .txt 備份重要內容。

AI 一鍵展開全部（選用，需自備 API 金鑰）

展開「API 連線設定」，選擇服務商（Claude／OpenAI／Gemini／OpenRouter），填入你自己申請的 API 金鑰；模型欄有預設值，也可以自行改成你想用的模型 ID。

  • 「🧠 AI 一鍵展開全部」會依目前主題一次生成 8 大面向、64 個子想法、總結與行動建議，直接覆蓋目前已填寫的內容（會先跳出確認）
  • 每張子九宮格旁的「🧠 AI 重新生成此面向」只會重新生成該面向的 8 個子想法，適合單一面向不滿意時局部重來
  • 沒有填 API 金鑰完全不影響使用——所有格子本來就可以直接手動編輯
API 金鑰要自己到各服務商網站申請，使用時依你與該服務商的方案計費，本工具不會向你收費，也不會經手你的金鑰——金鑰只存在你這台電腦的瀏覽器，且直接連到服務商官方 API，不會經過本工具以外的任何伺服器。
